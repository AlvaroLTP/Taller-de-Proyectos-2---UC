## SPRINT 1 — Gestión Core de Operaciones

### Objetivo del Sprint:

Permitir que el sistema tenga la información básica y validada de vehículos, pedidos y conductores para poder utilizarla posteriormente en la generación de rutas.

### Historias

### EP-01 – Gestión Core de Operaciones Logísticas

- US-002 — Gestionar parámetros operativos y ambientales

- US-004 — Registrar pedidos

- US-006 — Validar información de los pedidos
- US-007 — Registrar conductores
- US-008 — Gestionar disponibilidad de conductores
- US-009 — Validar información de conductores
### Enabler

- EN-002 — Implementar controles de seguridad
