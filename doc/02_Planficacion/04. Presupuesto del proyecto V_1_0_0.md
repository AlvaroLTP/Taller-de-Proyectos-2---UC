# 04. Presupuesto del proyecto V_1_0_0

## 1. Propósito y Marco Financiero

El presente documento establece el modelo financiero integral y la
Estructura Desagregada del Presupuesto (EDP) para el desarrollo del
Producto Mínimo Viable (PMV) **"EcoLogística Lima"**.

Conforme a las directrices de gobernanza del proyecto, el horizonte
temporal de ejecución es de **12 semanas**, operando bajo un esquema
híbrido con énfasis adaptativo. Dado que el equipo de desarrollo asume
el autofinanciamiento académico del proyecto, los costos de recursos
humanos se presentan mediante una **simulación de mercado (CAPEX
teórico)**, la cual **no se contabiliza** dentro de la suma del subtotal
de gasto monetario directo. El límite estricto de desembolso monetario
directo (*out-of-pocket*) autorizado para la infraestructura, servicios
y contingencia del PMV se fija en un máximo de **S/ 500**, priorizando
el uso de software de código abierto, planes gratuitos y créditos
educativos (*free tiers*).

## 3. Costos de Licenciamiento, Herramientas e Infraestructura Cloud (OPEX / Servicios Directos)

Los costos directos reflejan los gastos monetarios reales necesarios
para la puesta en marcha del PMV en un entorno cloud optimizado para
cumplir con la restricción presupuestal de S/ 500.

-   **Licenciamiento y Herramientas de Desarrollo:** Uso de entornos IDE
    de código abierto (VS Code / PyCharm Community), control de
    versiones en GitHub (Plan Gratuito Educativo), gestión de tareas en
    Jira/Trello (Free Tier), modelado en Figma (Educativo) y análisis
    estático con SonarQube Community. Costo directo: **S/ 0.00**
    (cubierto mediante licencias académicas y open source).
-   **Infraestructura Cloud y Servicios (OPEX):** Despliegue de
    micro-instancias de servidor en la nube (AWS/Render/Railway) o uso
    de créditos educativos, bases de datos gestionadas PostgreSQL con
    PostGIS, dominios de prueba y certificados SSL básicos (Let's
    Encrypt). Asignación presupuestal: **S/ 120.00**.
-   **APIs Georreferenciadas y de Tráfico:** Gestión controlada de
    consultas y optimización de llamadas a APIs de mapas y enrutamiento
    (OpenStreetMap / Leaflet sin costo de licenciamiento, con un fondo
    de contingencia para consumo de pruebas en endpoints externos si se
    requiere). Asignación presupuestal: **S/ 180.00**.
-   **Dominios, Servicios Técnicos y Respaldos:** Certificación técnica
    complementaria, dominios temporales y herramientas auxiliares de
    pruebas. Asignación presupuestal: **S/ 100.00**.

## 4. Reserva de Contingencia (Imprevistos)

De acuerdo con el análisis de riesgos del proyecto (enfrentando
desviaciones por consumo de APIs o ajustes de infraestructura en las 12
semanas), se establece una reserva de contingencia equivalente al **20%
del subtotal directo** (S/ 100.00), garantizando flexibilidad financiera
ante variaciones menores en el uso de servicios cloud.

*Aclaración final sobre la estructura presupuestal:* Los costos de
recursos humanos (CAPEX por un valor simulado de S/ 21,500.00) se
presentan exclusivamente con fines de modelado financiero y gestión de
proyectos, **quedando excluidos de la suma del subtotal final** debido a
que el proyecto se encuentra autofinanciado íntegramente por el equipo
de desarrollo. El presupuesto monetario directo efectivo de operación y
erogación del PMV se restringe estrictamente al tope máximo de **S/
500** en un periodo de **12 semanas**, cumpliendo cabalmente con las
directrices institucionales y el Acta de Constitución V_1_0_0.
