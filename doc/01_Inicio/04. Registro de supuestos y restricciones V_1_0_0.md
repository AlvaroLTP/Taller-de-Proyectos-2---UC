# Registro de supuestos y restricciones

## 1. Propósito del documento

El presente documento tiene como finalidad identificar, registrar y controlar los principales **supuestos y restricciones** que pueden influir en la planificación y ejecución del proyecto **“EcoLogística Lima”**, orientado al desarrollo de una plataforma web para la optimización sostenible de rutas de última milla de la empresa ficticia **DistriRápido S.A.C.**

El registro permitirá establecer las condiciones consideradas como válidas para la planificación inicial del proyecto, así como los factores que limitan su ejecución en términos de costo, tiempo, tecnología y normativa.

Los supuestos deberán ser validados progresivamente durante el desarrollo del proyecto, mientras que las restricciones deberán ser consideradas como condiciones de cumplimiento obligatorio o de negociación limitada.

# 4. Priorización de supuestos y restricciones

A partir del análisis inicial, se identifican como elementos críticos aquellos que pueden afectar directamente el cumplimiento del alcance, cronograma, costo o calidad del proyecto.

### Supuestos críticos

1. **AS-01a** Disponibilidad de información suficiente sobre pedidos, vehículos y conductores.
2. **AS-05a** Disponibilidad de parámetros para calcular consumo y emisiones.
3. **AS-06a** Viabilidad de implementar una metaheurística que genere soluciones válidas.
4. **AS-08a** Disponibilidad de información de tráfico.
5. **AS-13a** Disponibilidad del equipo para cumplir el cronograma.
6. **AS-14a** Capacidad de alcanzar el 70 % mínimo de funcionalidades del MVP.
### Restricciones críticas

1. **CO-01:** Tiempo máximo de 14 semanas para el proyecto.
2. **CO-02:** Implementación mínima del 70 % de los requerimientos RF-01 al RF-07.
3. **CO-03:** Tiempo máximo de 45 segundos para la generación de rutas.
4. **CO-04:** Tiempo máximo de 30 segundos para la re-optimización.
5. **CO-05:** Presupuesto máximo inicial de S/ 500 000 para el MVP.
6. **CO-08:** Cumplimiento de la Ley N.° 29733.
7. **CO-09:** Cumplimiento de las restricciones de tránsito consideradas.
8. **CO-17:** Aplicación de los estándares y normas definidos para el proyecto.
