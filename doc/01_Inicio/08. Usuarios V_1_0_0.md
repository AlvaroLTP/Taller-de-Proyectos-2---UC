## 3. Matriz de Control de Acceso (RBAC / ABAC)

La matriz define los permisos principales de cada rol sobre las capacidades del sistema **EcoLogística Lima**.

### Leyenda

- **CRUD:** Crear, consultar, actualizar y eliminar.
- **C:** Crear.
- **R:** Lectura / consulta.
- **U:** Actualizar.
- **D:** Eliminación.
- **Crear / Lectura:** Permite registrar y consultar información.
- **Sin Acceso:** El rol no tiene permisos sobre la capacidad indicada.
