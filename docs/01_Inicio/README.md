# 01. INICIO — EcoLogística Lima

## Descripción general

Esta carpeta contiene los documentos correspondientes a la fase de inicio del proyecto EcoLogística Lima — Optimizador de Rutas Sostenibles para DistriRápido S.A.C., desarrollado en el curso Taller de Proyectos II de la Universidad Continental.

La documentación comprende la selección del enfoque, constitución del proyecto, visión del producto, interesados, requisitos funcionales y no funcionales, usuarios, reglas de negocio, tecnologías, modelos de datos, arquitectura y restricciones.

## Relaciones documentales

El Acta de Constitución constituye la referencia inicial de objetivos, alcance, presupuesto y cronograma.

La Declaración de la Visión expresa los resultados esperados del producto.

Los Requisitos Funcionales y No Funcionales establecen las capacidades y condiciones de calidad que debe satisfacer el sistema.

El documento de Usuarios define los actores y perfiles, mientras que las Reglas de Negocio establecen las condiciones operativas.

El Stack Tecnológico, el Modelo de Base de Datos y el Modelo C4 describen las decisiones de diseño y arquitectura.

Los registros de Supuestos y Restricciones permiten identificar y controlar las limitaciones que condicionan el desarrollo.

## Convención de versiones

Los documentos originales se identifican mediante el formato `V_1_0_0`.

La revisión correctiva propuesta utiliza `V_1_0_1` para aquellos archivos cuyo contenido haya sido efectivamente modificado.

El historial individual de cada documento debe conservar las versiones anteriores e identificar las nuevas modificaciones.

## Estado de revisión
