## 1. Introducción, Propósito y Marco Financiero

### 1.1. Introducción

El presupuesto constituye un componente fundamental de la gestión del proyecto EcoLogística Lima, ya que permite identificar y organizar los recursos económicos necesarios para desarrollar el Producto Mínimo Viable (PMV).

El proyecto contempla el desarrollo de una plataforma web orientada a la optimización sostenible de rutas de distribución para la empresa ficticia DistriRápido S.A.C., utilizando tecnologías de código abierto y servicios de infraestructura de bajo costo.

Debido a su naturaleza académica, el proyecto considera tanto los gastos monetarios directos necesarios para su desarrollo como una valorización referencial del esfuerzo realizado por los integrantes del equipo.

### 1.2. Propósito

El presente documento tiene como propósito establecer la estructura presupuestaria del proyecto EcoLogística Lima, identificando los recursos humanos, las herramientas tecnológicas, los servicios de infraestructura y la reserva de contingencia considerados durante su planificación.

Asimismo, busca mantener la coherencia financiera con el Acta de Constitución y proporcionar una referencia para controlar los gastos durante las cuatro iteraciones de desarrollo establecidas para el proyecto.

### 1.3. Marco financiero

Conforme al Acta de Constitución V_1_0_1, el proyecto contempla una duración planificada de **12 semanas**, utilizando un enfoque híbrido con ejecución iterativa y adaptativa.

Para el desarrollo del PMV se considera un presupuesto monetario directo máximo de **S/ 500.00**, distribuido entre infraestructura, servicios geoespaciales, herramientas complementarias y contingencia.

El equipo de desarrollo participa bajo un esquema de trabajo académico. Por ello, las horas dedicadas al proyecto se presentan mediante una valorización económica simulada, sin considerarse desembolsos monetarios dentro del presupuesto directo.

Se distinguen dos categorías:

1. **Presupuesto monetario directo:** recursos económicos previstos para servicios, infraestructura, herramientas complementarias y contingencias durante el desarrollo del PMV.

2. **Valorización referencial de recursos humanos:** estimación económica del esfuerzo del equipo utilizando tarifas horarias supuestas, exclusivamente con fines de análisis.

Ambas categorías se presentan por separado para evitar que los costos simulados se interpreten como gastos efectivamente realizados.

El monto de S/ 500.00 se utiliza como línea base documental provisional, pendiente de cualquier conciliación o aprobación formal que corresponda.

## 3. Costos de Licenciamiento, Herramientas e Infraestructura

### 3.1. Descripción

El desarrollo de EcoLogística Lima prioriza tecnologías de código abierto, herramientas gratuitas y servicios que permitan controlar el consumo de recursos.

El presupuesto considera asignaciones económicas para cubrir necesidades de desarrollo, pruebas, integración y despliegue del PMV.

Los montos establecidos representan límites de planificación por categoría y no gastos ejecutados.

### 3.2. Licenciamiento y herramientas de desarrollo

Se contempla el uso de herramientas que permitan desarrollar y administrar el proyecto sin incurrir inicialmente en costos obligatorios de licenciamiento.

| Herramienta | Uso previsto | Costo de licencia presupuestado |
|---|---|---:|
| Visual Studio Code / IDE equivalente | Desarrollo de software | S/ 0.00 |
| Git y GitHub | Control de versiones y repositorio | S/ 0.00 |
| Jira, mediante plan gratuito o acceso disponible | Gestión del Product Backlog y sprints | S/ 0.00 |
| Figma, mediante modalidad gratuita o educativa | Diseño de interfaces | S/ 0.00 |
| Herramientas gratuitas de análisis estático | Revisión de calidad del código | S/ 0.00 |
| React | Desarrollo frontend | S/ 0.00 |
| Python y FastAPI | Desarrollo backend | S/ 0.00 |
| PostgreSQL y PostGIS | Persistencia de datos | S/ 0.00 |
| Leaflet | Visualización cartográfica | S/ 0.00 |
| **Total previsto de licenciamiento** | | **S/ 0.00** |

La ausencia de costo de licenciamiento no implica que el alojamiento, almacenamiento, consumo de API u operación de estas herramientas sea necesariamente gratuito.

El uso de servicios externos estará sujeto a sus condiciones de acceso, cuotas y licencias vigentes.

### 3.3. Infraestructura cloud y base de datos

**Asignación presupuestal: S/ 120.00**

Se considera esta partida para cubrir posibles gastos relacionados con:

- Alojamiento del frontend.
- Ejecución del backend.
- Servicio de base de datos PostgreSQL/PostGIS.
- Almacenamiento necesario para pruebas.
- Consumo básico de recursos cloud.

El proyecto podrá utilizar proveedores que ofrezcan planes gratuitos, créditos educativos o servicios de bajo costo.

La selección definitiva deberá considerar disponibilidad, límites del servicio y compatibilidad con la arquitectura.

### 3.4. API y servicios geoespaciales

**Asignación presupuestal: S/ 180.00**

Esta partida contempla posibles consumos asociados con servicios de:

- Geocodificación.
- Obtención de matrices de distancias y tiempos.
- Enrutamiento.
- Consulta de información geoespacial.
- Tráfico, cuando exista una fuente aprobada y disponible.

La visualización mediante Leaflet y los datos de OpenStreetMap no garantizan por sí solos la disponibilidad gratuita de servicios de geocodificación, optimización o tráfico.

Para controlar estos costos se contempla:

1. Limitar las consultas a servicios externos.
2. Supervisar las cuotas disponibles.
3. Evitar solicitudes repetitivas innecesarias.
4. Utilizar alternativas de código abierto cuando sean viables.
5. Mantener desacopladas las integraciones mediante adaptadores.

### 3.5. Dominios y servicios técnicos complementarios

**Asignación presupuestal: S/ 50.00**

Esta categoría comprende posibles gastos relacionados con:

- Dominio de prueba, si fuese necesario.
- Configuración de servicios técnicos complementarios.
- Recursos adicionales de conectividad o despliegue.
- Otros servicios técnicos requeridos dentro del alcance aprobado.

Se priorizará el uso de certificados HTTPS gratuitos cuando sean compatibles con la infraestructura seleccionada.

### 3.6. Pruebas, respaldos y herramientas auxiliares

**Asignación presupuestal: S/ 50.00**

Esta partida considera posibles gastos relacionados con:

- Pruebas técnicas.
- Respaldo de información.
- Almacenamiento auxiliar.
- Herramientas complementarias de validación.
- Recursos técnicos necesarios para verificar el funcionamiento del PMV.

La utilización de estos recursos deberá ajustarse a las necesidades del proyecto y a los límites económicos establecidos.

## 4. Reserva de Contingencia

### 4.1. Descripción

La reserva de contingencia permite atender determinados gastos imprevistos que puedan presentarse durante el desarrollo del proyecto.

Se establece una asignación de **S/ 100.00**, equivalente al **20 % del presupuesto monetario directo total de S/ 500.00**.

Esta reserva representa el 25 % de los S/ 400.00 asignados a las categorías anteriores a contingencia.

### 4.2. Riesgos considerados

La reserva podrá utilizarse, de acuerdo con los controles presupuestarios aplicables, para atender situaciones como:

- Consumo adicional de API geoespaciales.
- Necesidades imprevistas de infraestructura.
- Ajustes técnicos necesarios para pruebas.
- Recursos auxiliares requeridos durante la integración.
- Gastos adicionales derivados de riesgos identificados.

La reserva no constituye una autorización automática para incorporar funcionalidades fuera del alcance.

Cualquier gasto que exceda el límite presupuestario aprobado deberá evaluarse mediante el procedimiento de control de cambios del proyecto.
